# 年度报告

看一个人某一年（立春到下一个立春）怎么走：八字的流月、星盘的行运和天象、印占的运、出厂底色，加一节「玄玑怎么看」。出一份手机上看的报告。

## 什么时候出

他说「我的 2027 怎么走」「帮我看看明年」，或者从别的报告的对话卡回来发了「这件事放在我今年的运里是什么位置」。先有他的单人盘（`profile.json`），没有就照 `SKILL.md` 先排。

## 拿数据

1. 问一句他**现在住在哪**（跟出生地不在一个地方时）：「要不要按你现在住的地方看？星盘里有一层会跟着住处变。」他愿意，就在请求里加现在住的城市；在中国以外的城市，加大致的经纬度（保留两位小数）。不愿意就不加。
2. 写 `year_request.json`（私有创建）：`profile` 那份请求的生辰字段，加 `year`（要看的那一年，整数），加 `tz`（他所在地的时区，比如 `Asia/Shanghai`、`America/Los_Angeles`，日子都按它出），可选 `now_city` 或 `now_place: {lat, lon}`。

```bash
node <skill目录>/scripts/client.mjs year --input year_request.json --output year.json
```

3. 「玄玑怎么看」：同一份内容加 `"kind": "year"`，写成 `xuanji_request.json`：

```bash
node <skill目录>/scripts/client.mjs xuanji --input xuanji_request.json --output xuanji_year.json
```

`xuanji_year.json` 回的是：全年最要紧的月和事（`key`）、另外要紧的一两个月（`also`）、最该收着的一两个月（`careful`）。**报告里标「要紧」「留神」的月份，以它为准**，报告跟玄玑怎么看不打架。怎么挑出来的，不问不猜不解释。

## year.json 里有什么

- `span`：这一年从哪天到哪天（按 `tz`）。
- `bazi.year_gz`、`bazi.luck`：流年干支、所在的大运（还有引擎给这步大运的那句话）。
- `bazi.year_light`：引擎给这一年的档位、亮的领域（`bazi`、`west`）、两套都指的（`mirror`）。
- `bazi.months`：十二个流月，每个月有干支、起止日子、天干地支的十神、喜忌（`tone`：正是顺、负是压）、跟原局四柱／流年／大运的关系（冲、六合、刑、害、伏吟、自刑）、凑成的局（三合、半合、三会、三刑，`god` 是这个局对他是财、官杀、印、食伤还是比劫）、领域提示（`hints`）。
- `bazi.lit_months`：这一年已经亮的领域，最可能应在哪几个月。
- `west.windows`：这一年的行运窗口（谁碰了本命哪颗星、管哪一块、顺风还是压力、精确到哪天）；`west.relocated` 是按现在住处算的那一层（有才有）。
- `sky`：日月食（落在哪一宫、碰到本命哪颗星）、三次水逆（落在哪几宫、停在哪颗星上）、木星土星换座。
- `vedic`：印占的上升、这一年走的大运小运段、木星土星罗睺换座落在他第几宫。
- `persona`：出厂底色的字母、称号、那句夸人的话。

时辰不详时没有星盘宫位、没有印占；报告照实少写那几块，不硬补。

## 写之前先想清楚的三件事

1. **这一年一句话**：一个主题、一句气候（比如「春天出场，夏秋扎根，冬天结伴」）。用 `xuanji_year.json` 的要紧月和收着月搭骨架。
2. **几条线**：把这一年的日子按事情连成三到四条线（比如「被看见 → 变成人脉 → 引来搭档」「挣钱的路子换一层皮」「跟人分钱」「家和身体」），每条线写清前因后果，再看几条线交在哪几个月。
3. **玄玑建议的步骤**：几条线谁带出谁，画成一张图；再写成五到六步，每一步写什么时候、做什么、为什么。这一张是整份报告最重要的，其余都是论证。

## 报告分四卷

封面「玄玑看见的你的 ××××」：照本命报告的封面三句判词——第一句八字给气势（一句成语或名句），第二句星盘给本事（半文半白像口诀，14 到 28 个字），第三句从出厂底色那句改到这一年；三句里不放术语，术语挪到下面一行小字「依据」；右上角盖印章，印章上是这一年的关键词（两个字），摆正。下面一张卡写年度关键词、一句话说这一年、四套同看（八字、星盘、印占、出厂底色各一行）、四卷目录。

1. **一眼看懂**：全年最要紧的那个月（标哪两套指着它）和三个要点；**玄玑建议的步骤**（因果图＋几步＋每步为什么＋一句话记住）；全年气候曲线（每个月一个点，要紧的、留神的标出来）和三段季节。
2. **来路去路**：先看去年——说中他去年的一件事，肯定、带一层质地、一件事不并列；再是你走到人生哪一段——八字大运、印占大运小运、星盘大周期各说一段，最后写三套在哪几年一起换挡。
3. **五个方面**：事业、钱、感情、身体、家人和人际，每块写气候、凭什么（标是哪一套）、要抓、要防、军师谏言。顶上一排五个格子，点了跳到那一块，每块底下有回去的链接。
4. **串起日子**：几条线画成一张图（竖着是月份，每条线一列），每条线一张卡、最后一句写「这条线说的是」；几条线交在哪几个月；十二个月一排格子，要紧的、留神的月份展开写（样子、凭什么、适合做的两三条、留神、日子），其余每月三句；最后是天上的大日子（水逆、日月食、木土换座），说清碰到他哪一块，碰不上的直说不用担心。

收尾：「玄玑怎么看」（全年最要紧的月和一句话，后面两扇门）；「回到这一年」三级台阶、两件别做的事、「一句话记住」、「到时候回来发这一句」；「接下来可以问我」三个问题；创始人那张卡。

## 写法

- 每一句都要能指回 `year.json` 或 `profile.json` 里的字段；干支、日子一律抄，不自己算；日子按 `tz`。
- 讲月份照节气分月，写成「3 月（3/5 到 4/3）」。
- **翻成今天的样子**：古书的「名分」，对做事、创业的人是「身份立起来、有了自己的作品、有人上门谈」，有单位的人才是头衔升职；对不上他的现实就换一种说法，说最可能的那一种。
- **讲时间年纪只占小头**，现状为主。
- 同一颗星在星盘和印占里各碰一次，算一件事，不算两套都指。
- 要抓、要防各写两三句，带月份和具体做法。
- 军师谏言按这一块挑这一行公认最懂的真人，只用公开身份和公开讲过的办法，每份按人挑，不写死几个名字；一条线管两种可能（比如伴侣和合作方）时，谏言两种各给一条。
- 不写「那股劲」「这股劲」「带劲」，不连着用「亮」做比喻；收尾不用「X 不轻，但……」，直接说顺的话（「每一步都踩得稳」）。
- 「一句话记住」「擅长」「关键一步」用醒目的标；不放读者点了没反应的勾选框。
- 健康只讲作息和留神的时段，不诊断；钱只讲节奏和守什么，不给买卖点位。

## 出文件

写 `year_report.json`（私有创建），再执行：

```bash
node <skill目录>/scripts/build_doc.mjs --kind year --profile profile.json --year year.json --view xuanji_year.json --report year_report.json --out year.html --pdf year.pdf
```

查不过就照提示改了再跑；出不了完整的，照 `SKILL.md` 第 6 步什么都不给、请他加创始人微信。

## 机关：把他带回对话

「玄玑怎么看」后面接两扇门：

> 「三套盘分开说说我的 ××××」 → 接到分术报告
> 等那件事真来了：「帮我起一卦：××」 → 接到一事一卜（××写成这一年最要紧那件事的样子）

收尾写「到时候回来发这一句」：「玄玑，×月那件事来了」 → 回来对一对，照 `SKILL.md`「对过的事」记下来。
