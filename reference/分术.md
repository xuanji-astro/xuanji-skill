# 分术报告

一件事，四套盘各说各的：八字、星盘、印占、出厂底色围着同一个题目分开说，最后一页并排对照、只列不判，让他自己论证。

## 什么时候出

他心里装着一件事、想看几套盘分别怎么说：「三套盘各自怎么看我的事业」「三套盘分开说说我的 2027」「我用 AI 做玄学这件事，几套盘怎么看」。题目从他的话里来，一份只答一件。

**不拆人生结构报告**：那份本来就是几套合起来看人，拆开只是同样的话说四遍。他想看每套盘怎么推出来的，指他去人生结构报告后面的「溯源」。

## 拿数据

- 都要有他的单人盘 `profile.json`（里面有八字、星盘、出厂底色，`vedic` 是印占；时辰不详没有印占）。
- 题目是某一年的，再照 [年度报告](年度.md) 拿 `year.json`。
- 「玄玑怎么看」：写 `xuanji_request.json`，生辰字段加 `"kind": "fenshu"` 和 `"theme"`——某一年写 `"year"`（再加 `year`），否则从 事业认可、钱、感情、家庭、工作、迁移远方、自我 里挑最贴的一块：

```bash
node <skill目录>/scripts/client.mjs xuanji --input xuanji_request.json --output xuanji_fenshu.json
```

回的是：几套盘有没有指着同一段（`lean`、`agree`）、最近最要紧的那一年（`key_window`）。一年的题目回的跟年度报告一样。怎么得出来的，不问不猜不解释。

## 报告分四卷

封面「玄玑看见的你 · 这件事」：照本命报告的封面三句判词（八字给气势、星盘给本事、出厂底色那句改到这件事上），术语挪到小字「依据」，右上角印章写这件事的关键词（两个字），摆正。下面一张卡写他问的原话、一句话结论、四套各一句、四卷目录。

1. **一眼看懂**：一张格子——横着是这件事的三个方面（比如问做一行：天赋、回报、地位；问感情：缘分、相处、走向；问一年：前半年、后半年、要紧的事），竖着是四套盘，每格两三行短话；**玄玑建议的步骤**（一张从上往下的梯子图、几步、每步为什么、一句话记住）。
2. **分开细看**：四套盘各一张卡，**小标题完全一样**，方便横着比：
   1. 这套盘怎么看你
   2. 它的结论
   3. 凭什么（盘上哪几处，翻成白话）
   4. 它给的时间
   5. 它提醒你的（要抓、要防）
   6. 这套盘擅长看什么——八字长于节奏和十年大运，星盘长于具体月份和事情的样子，印占长于人生分段，出厂底色只看人、不看事也不看时间；用醒目的「★ 擅长」标，不用灰
3. **对照一页（只列，不判）**：
   - 几套都这么说的：每条右边四个小章，哪套指着哪个就亮；
   - 各说各的：同一个小问题，四套并排，不评谁对谁错；
   - 你自己来对一对：两三条能自己核对的（他过去的某一年、最近的某个月、马上要来的那段），每条底下一个「回到对话里发：对一对：××」的气泡；他在对话里对过、说中了的（`hits.json` 里有的），那一条直接显示绿勾和他说过的话。
4. **玄玑怎么看**：几套说一样的地方最该信；几套说法不一样的那几处，玄玑偏哪一边，一句话；后面两扇门。

收尾：「接下来可以问我」三个问题，顺着几套说法不一样的地方往下问；创始人那张卡。

## 写法

- 每一套的依据只用那一套盘上有的，别家的证据不安到它头上；时辰不详少的那几块照实少写。
- 「凭什么」翻成白话：术语一处最多一个，紧跟一句人话。
- 同一颗星在星盘和印占里各碰一次，算一件事，不算两套都指。
- 翻成今天的样子、讲时间年纪只占小头、军师按行当挑人、不写「那股劲」、不连着用「亮」、新标醒目、不放点不了的勾选框——跟 [年度报告](年度.md)「写法」一样。

## 出文件

写 `fenshu_report.json`（私有创建），再执行：

```bash
node <skill目录>/scripts/build_doc.mjs --kind fenshu --profile profile.json --view xuanji_fenshu.json --report fenshu_report.json --out fenshu.html --pdf fenshu.pdf
```

一年的题目再带 `--year year.json`；他对过的事有记录（本次工作目录里有 `hits.json`），再带 `--hits hits.json`，「你自己来对一对」里对上的那一条写 `hit_id`。查不过就照提示改；出不了完整的，照 `SKILL.md` 第 6 步什么都不给、请他加创始人微信。

## 机关：把他带回对话

> 等事情真来了：「帮我起一卦：××」 → 接到一事一卜
