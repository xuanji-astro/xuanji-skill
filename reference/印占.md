# 印占排盘（印度占星）

用户说「看看我的印度占星」「印占」「吠陀占星」「Jyotish」「我的月宿」「我现在走什么大运」这一类，走这里：先出一份印占排盘报告（盘和数据，不写解读），再在对话里照下面的读法回答他问的。

## 拿数据

1. 生辰跟单人排盘一样（公历日期、时间、出生城市、性别），同一次对话里已经同意过排盘的不用再问；没同意过，照 `SKILL.md`「数据与范围」那段先问。**没有出生时间排不了印占**：没有时辰就没有上升，整盘不排，照实说，不用别的顶替。
2. 照第 2 步私有创建 `vedic_request.json`，只放这几样：`date`、`time`、`city`、`gender`，可选 `time_source`、`time_precision`。不要把 `answers`、`calib` 放进来。
3. 拿整盘：

```bash
node <skill目录>/scripts/client.mjs vedic --input vedic_request.json --output vedic.json
```

## 出报告

```bash
node <skill目录>/scripts/build_vedic.mjs --vedic vedic.json --out 印占排盘.html --pdf 印占排盘.pdf --pack 印占数据包.txt --zip 印占排盘.zip
```

- 想看南印度方盘的加 `--style south`，默认北印度菱形盘。
- `REPORT_SAVED`、`PDF_SAVED`、`PACK_SAVED`、`ZIP_SAVED` 都出来了，就把压缩包交给他；`PDF_SKIPPED_…` 时压缩包里只有网页版和数据包，照第 6 步说明。
- `VEDIC_TIME_UNKNOWN`：没有出生时间，照实说排不了印占。
- `OUTPUT_EXISTS` 换个文件名；`REPORT_INCOMPLETE`、`VEDIC_INVALID` 什么都不给，照第 6 步请他加创始人微信。
- 交压缩包时说一句：里面是印占排盘报告（PDF 和网页版）和一份「印占数据包.txt」，数据包可以整段贴给手机上别的 AI 接着聊；想照玄玑的读法深聊，就在这里接着问。

报告里是盘、九曜、六力、宫位力、相位、大运到第四级、八分力、七年半和火星煞、十六张分盘和细表，没有解读文字。不印出生日期、时间和地点，但盘面推算结果仍是他的个人信息。

## 对话里怎么读

先问他最想知道什么；他没说，就按下面的顺序挑跟他最有关的两三样讲，一次不倒完。每句话都要能指回 `vedic.json` 里的字段，没给的星、宫、日子不自己算。

1. **三个「我是谁」**：月亮星座（印度人说的「你是什么座」）、月亮月宿、上升。讲性格用他生活里会遇到的事说，不堆梵文。
2. **哪几颗星最有力、哪几颗吃力**：六力（`shadbala`，过没过及格线）、庙旺陷（`dignity`）、九分同座（`vargottama`）、燃烧（`combust`）一起看，不拿一个数字定好坏。宫位力（`bhava_bala`）讲哪几块人生最有劲。
3. **现在走到哪**：大运、小运、第三级（`dasha_days`，当前那段标着），讲这一段是什么气候、适合做什么、该收着什么；第四级几天一段，只在他问很近的日子时提。出生时间有误差，交接日前后差几十天，照 `dasha_err_days` 说。
4. **分盘**：九分盘看婚姻和每颗星的后劲；事业看十分盘，子女看七分盘，以此类推。`asc_stable` 是 false 的分盘只看星落哪个座，不看宫位。
5. **常被问的**：土星七年半、火星煞、罗计夹、宫主互换只当参考，不吓人、不说灾、不卖化解（宝石、念咒、法事一律不推）。
6. **跟八字、星盘一起看**：同一件事几套盘都指向，可以说得满一点；只有印占看到的，说明是印占这么看。印占的过运和星盘的行运是同一批天上的星，算一次，不重复计票。要几套分开说，走分术报告。

古书里的名分翻成他今天的样子讲：「第十宫有力」不说「当官」，说他在做的事、在哪一行出头。不说狠话，不判阶层。
