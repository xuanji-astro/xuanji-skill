# 印占排盘（印度占星）

用户说「看看我的印度占星」「印占」「吠陀占星」「Jyotish」「我的月宿」「我现在走什么大运」这一类，走这里：先出一份印占排盘报告（盘和数据，不写解读），再在对话里照下面的读法回答他问的。

## 拿数据

1. 生辰跟单人排盘一样（公历日期、时间、出生城市、性别），同一次对话里已经同意过排盘的不用再问；没同意过，照 `SKILL.md`「数据与范围」那段先问。**没有出生时间排不了印占**：没有时辰就没有上升，整盘不排，照实说，不用别的顶替。
2. 照第 2 步私有创建 `vedic_request.json`，只放这几样：`date`、`time`、`city`、`gender`，可选 `time_source`、`time_precision`。不要把 `answers`、`calib` 放进来。
3. 拿整盘：

```bash
node <skill目录>/scripts/client.mjs vedic --input vedic_request.json --output vedic.json
```

## 出报告

```bash
node <skill目录>/scripts/build_vedic.mjs --vedic vedic.json --out 印占排盘.html --pdf 印占排盘.pdf --pack 印占数据包.txt --zip 印占排盘.zip
```

- 想看南印度方盘的加 `--style south`，默认北印度菱形盘。
- `REPORT_SAVED`、`PDF_SAVED`、`PACK_SAVED`、`ZIP_SAVED` 都出来了，就把压缩包交给他；`PDF_SKIPPED_…` 时压缩包里只有网页版和数据包，照第 6 步说明。
- `VEDIC_TIME_UNKNOWN`：没有出生时间，照实说排不了印占。
- `OUTPUT_EXISTS` 换个文件名；`REPORT_INCOMPLETE`、`VEDIC_INVALID` 什么都不给，照第 6 步请他加创始人微信。
- 交压缩包时说一句：里面是印占排盘报告（PDF 和网页版）和一份「印占数据包.txt」，数据包可以整段贴给手机上别的 AI 接着聊；想照玄玑的读法深聊，就在这里接着问。

报告里是盘、九曜、六力、宫位力、相位、大运到第四级、八分力、七年半和火星煞、十六张分盘和细表，没有解读文字。不印出生日期、时间和地点，但盘面推算结果仍是他的个人信息。

## 对话里怎么读

先问他最想知道什么；他没说，就按下面的顺序挑跟他最有关的两三样讲，一次不倒完。每句话都要能指回 `vedic.json` 里的字段，没给的星、宫、日子不自己算。

1. **三个「我是谁」**：月亮星座（印度人说的「你是什么座」）、月亮月宿、上升。讲性格用他生活里会遇到的事说，不堆梵文。
2. **哪几颗星最有力、哪几颗吃力**：六力（`shadbala`，过没过及格线）、庙旺陷（`dignity`）、九分同座（`vargottama`）、燃烧（`combust`）一起看，不拿一个数字定好坏。宫位力（`bhava_bala`）讲哪几块人生最有劲。
3. **现在走到哪**：大运、小运、第三级（`dasha_days`，当前那段标着），讲这一段是什么气候、适合做什么、该收着什么；第四级几天一段，只在他问很近的日子时提。出生时间有误差，交接日前后差几十天，照 `dasha_err_days` 说。
4. **分盘**：九分盘看婚姻和每颗星的后劲；事业看十分盘，子女看七分盘，以此类推。`asc_stable` 是 false 的分盘只看星落哪个座，不看宫位。
5. **常被问的**：土星七年半、火星煞、罗计夹、宫主互换只当参考，不吓人、不说灾、不卖化解（宝石、念咒、法事一律不推）。
6. **跟八字、星盘一起看**：同一件事几套盘都指向，可以说得满一点；只有印占看到的，说明是印占这么看。印占的过运和星盘的行运是同一批天上的星，算一次，不重复计票。要几套分开说，走分术报告。

古书里的名分翻成他今天的样子讲：「第十宫有力」不说「当官」，说他在做的事、在哪一行出头。不说狠话，不判阶层。

## 两个人：印占合盘（36 分配对）

用户问「印度人那种合盘」「36 分配对」「Milan」「我们俩火星煞配不配」这一类，走这里。跟 [合盘](合盘.md) 一样只在对话里讲，不出报告文件。

1. **收 TA 的信息、取得同意**：照 [合盘](合盘.md) 第 1 步，不复述 TA 的完整生辰。**两个人都要有出生时间**，任何一方没有，就照实说印占合盘做不了，普通合盘照做。
2. **两张盘**：用户自己的照上面「拿数据」拿 `vedic.json`。TA 的另建一份 `vedic_ta_request.json`（同样只放 `date`、`time`、`city`、`gender`），拿 `vedic_ta.json`：

```bash
node <skill目录>/scripts/client.mjs vedic --input vedic_ta_request.json --output vedic_ta.json
```

3. **算分**（只在本机算，不联网）：

```bash
node <skill目录>/scripts/vedic_milan.mjs --a vedic.json --b vedic_ta.json --sex-a <用户 male|female> --sex-b <TA male|female> --relation <用户说的关系> --out milan.json
```

- `MILAN_SAVED`：照下面讲。
- `VEDIC_TIME_UNKNOWN`：有一方没有出生时间，照第 1 步说。
- `VEDIC_INVALID`：什么都不给，照第 6 步请他加创始人微信。
- `OUTPUT_EXISTS`：换个文件名。

### 怎么讲

每句都要能指回 `milan.json` 里的字段。`--relation` 传用户说的关系（恋人／暧昧／家人／朋友／同事／客户／其他），`relation.group` 是读法：`love`（恋人、暧昧、没说）照 1～5 条讲 36 分；`friend`、`family`、`other`（同事、客户、其他）照第 6 条讲。不管哪种关系，都讲第 9 条前世业力、第 10 条本命动物。

顺序：先报分 → 前世业力 → 合得来的几项 → 本命动物 → （恋人才有）火星煞。

1. **先报总分**：`total` 分（满分 36），档是 `band`，跟印度常见排盘网站算的是同一个数。说一句这在印度人眼里算什么：18 分以下他们觉得要慎重，25 分以上算好。`total_effective` 比 `total` 高，是因为下面第 3 条有扣分被抵掉了，补一句「算上抵掉的是 `total_effective` 分」。最后补一句：这是印度人婚配看的一套老规矩，是参考，不是判决。
2. **八项挑着讲**（`kootas`）：拿满分的挑一两项，说「这一项你们很顺」；最低的挑一两项，说是哪一种不合、日子里会在哪摩擦，再给一个相处的办法。用 `name` 里的中文说法讲，不堆梵文。
   - 动物（`yoni` 的 `a`、`b`）、天人罗刹（`gana`）、三脉（`nadi`）、两人月亮星座的主星（`maitri`）可以点出来。
   - **心性层次那一项（Varna）只说得没得分，不说种姓名**，不判阶层。
3. **扣分那两项**（`kootas` 里 `nadi`、`bhakoot` 的 `raw_dosha`）：说是哪一项扣了分。`cancellation_reason_codes` 有理由码的，照 `reasons` 里那句中文补一句「按常见说法，这一条可以抵掉，因为……」。不说影响生育，不说灾。
4. **火星煞**（`manglik`）：照 `verdict` 说一句。某一方 `cancel` 有理由码的（火星在自己的座、入旺），说一句为什么不算；`mitigation` 有的（木星同座或照到火星），只说「有木星缓一缓」，不说彻底没了。不吓人，不说克夫克妻，不卖化解：宝石、念咒、法事一律不推。
5. **不是一男一女时**（`roles.traditional` 是 false）：先说这套配对本来按一男一女定方向，这里当参考看。
6. **不是恋人、夫妻**（`relation.group` 是 `friend`、`family`、`other`）：报 `rel_score.pct` 分（百分制），档是 `rel_score.band`，补一句「印度那套 36 分是给夫妻看的，朋友之间（一家人／平常打交道）只算用得上的 `rel_score.keys` 这几项，换成百分制」。36 分原分用户问了再说。八项只讲 `rel_score.keys` 里拿到一半分以上的，只说好的：这一项让你们在哪儿合拍、谁能帮到谁；一项都没过半，就讲分最高的那一项。火星煞不讲（那是婚配看的）。
7. **跟普通合盘一起看**：同一次对话里做过八字、星盘的合盘，几套同指的才说重话；只有 36 分这么看的，说明是印度人这套这么看。
8. 合盘的铁律照样用：主语是你，不评判 TA，不替 TA 表态，每个风险配一个办法。

9. **前世业力**（`karma[]`）：挑分量最重的三四条讲，`ketu` 先讲。主语照「你」和 TA，`from` 是 `a` 就是你的星、`b` 就是 TA 的星。
   - `ketu`：某人的星压在对方计都上（计都＝南交点，看前世带来的东西），`orb` 是差几度。是什么身份看 `role`（耶米尼代表星）：`BK` 兄弟星＝前世是姐妹／兄弟（两人同性才这么说，不同性说手足）；`MK` 母亲星＝前世对方像母亲一样照顾过星的主人；`PK` 子女星＝前世星的主人带过对方，像师父带徒弟；`AmK` 事业星＝前世一起做过事，一个出主意一个拿主意；`GK` 对手星＝前世不打不相识，这辈子换到同一边；`DK` 伴侣星＝恋人说前世的另一半，别的关系说前世结过很深的伴；`AK` 灵魂星＝前世灵魂就认得。写法照「你的兄弟星是火星，正好压在 TA 的计都上，只差 7 度」。
   - `rahu`：压在对方罗睺上（北交点，看这辈子要往哪走）：星的主人是推着对方往前走的人。
   - `flip`：两人南北交点对调：互相是对方的来处和去处。
   - `same_ak`：两人灵魂星（阿特玛卡拉卡，Atmakaraka）是同一颗，这辈子要修的功课一样（太阳＝自己站得住、活得有尊严；月亮＝情感、安全感、怎么照顾人；火星＝勇气；水星＝表达和学习；木星＝智慧和信念；金星＝爱和美、怎么经营关系；土星＝责任和耐心）。
   - `saturn`：某人的土星贴着对方的月亮／太阳／金星，土星是业力星、管长久：这段缘走得长，对方心里踏实。
   - `house`：某人的木星／月亮／金星落在对方的十二宫（前世、看不见的地方）、九宫（福德、贵人）、五宫（前世功德宫），`at` 里写着是从上升还是从月亮数的。木星落九宫说是贵人，落十二宫说在暗处护着，落五宫说是前世修来的。两个方向都有，就说「互相是对方的福气」。TA 时辰不准时只用从月亮数的那条。
   - `karma` 是空的：恋人、朋友、家人说「这辈子新结的缘，没有旧账要还」；路人不讲这一节。路人有也只讲 `ketu`、`rahu`、`flip` 里最重的一条。
   - 只讲好的，不说「还债」「孽缘」，不卖化解。
10. **本命动物**（`animals`）：月亮落的宿配成 14 种动物，每人一只。**不说公母**，中文名后面带英文名（`animals.a.en`），写成「你的本命动物是狮（Lion，月亮在虚宿），TA 的是虎（Tiger，角宿）」；别写「你是狗」「TA 是狗」这种能听成骂人的句子，一律说「本命动物是……」。各一句动物性格；两只动物怎么配看 `animals.pair`：`same` 同类相聚一拍即合，`big_cats` 两只大猫各有地盘也都护着自己人，`friendly` 天生处得来，`different` 各有各的本事互相长见识，`complement` 一快一慢正好互补，`rivals` 老规矩里是天敌，说成谁也不服谁、较着劲一起变强。当好玩的讲，不打分。
