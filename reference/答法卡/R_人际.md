# 答法卡·R 人际（5 题）

先照 `00_通则.md`。下面每题：年份怎么定、盘上讲什么、单件事怎么办、要摸清的现状说成判断、请哪类军师。

## R01 我在人群里是什么位置
- **年份**：这题不报具体年份（今年、这步大运的大气候可以带一句）；换了团队或身份时，再补当前环境把哪种位置推到前面。
- **盘讲**：八字看比劫、官杀、印星、食伤各自承担的同伴、规则、支持与表达角色，讲他更容易成为带头、协调、专业支持还是输出意见的人；强弱、喜忌只作辅助（身强身弱照接口口径，没核过，这条只当线索、不当主依据）。西占看十一宫的朋友群体、六宫的同事关系与十宫的权责位置。印占看十一宫、六宫、十宫及其宫主，讲在群体里的资源、服务与地位角色。只说常见位置，不把所有群体一概而论。
- **说成判断**：他想看的是朋友群、职场团队还是家庭群体；自己通常被推到做决定、收拾局面、提供专业，还是维持气氛的位置。
- **军师**：若要调整团队角色，请组织发展或团队教练领域的人结合真实反馈评估。

## R02 我适合独处还是合群
- **年份**：这题不报具体年份（今年、这步大运的大气候可以带一句）；处在高压或环境变化期时，再补当下更需要恢复还是连接。
- **盘讲**：八字看比劫对命局是支持还是消耗，讲同伴关系带来助力还是竞争；喜忌与强弱只作线索（身强身弱照接口口径，没核过，这条只当线索、不当主依据）。西占看七宫、十一宫的连接需要，以及八宫、十二宫和海王星带来的耗竭与退隐需要。印占看七宫、十一宫与六八十二宫的连接和消耗。结论讲适合怎样的社交密度与恢复方式，不贴“必须独处”或“必须合群”的标签。
- **说成判断**：他在人群里是获得能量还是承担过多；独处对他是恢复、逃避，还是整理后重新连接。
- **军师**：若社交或退缩已经影响生活功能，请心理咨询或社交技能领域的人协助判断。

## R03 为什么别人对我的第一印象和熟了以后不同
- **年份**：这题不报具体年份（今年、这步大运的大气候可以带一句）；最近换环境时，可补哪一面正在被新环境放大。
- **盘讲**：八字看食伤对外表达、比劫的互动方式与内里承压结构，讲表层表现和长期相处的落差；强弱、喜忌只作线索（身强身弱照接口口径，没核过，这条只当线索、不当主依据）。西占以上升、金星看初见感，以月亮、土星看熟悉后的情绪和边界。印占比较上升的外显气质与月亮、七宫宫主的长期相处方式。只讲落差从哪里来，不说哪一面是假的。
- **说成判断**：别人初见最常把他看成什么、熟后又改成什么；落差主要发生在亲密关系、朋友还是工作场合。
- **军师**：若落差持续造成误会，请沟通训练或人际心理领域的人用实际反馈校准表达。

## R04 我在团队里适合什么角色
- **年份**：以目前团队、项目周期和职责变化定；没有具体团队时，只讲角色类型，不硬报何时升迁或换位。
- **盘讲**：八字看官杀的带领与规则、印星的专业支持、食伤的创意输出、比劫的执行与凝聚，讲更能承担哪类角色；强弱、喜忌只作线索（身强身弱照接口口径，没核过，这条只当线索、不当主依据）。西占看太阳、火星的带领，水星、土星的专业与结构，金星、月亮的协调，以及天王星或一宫的独立开创。印占看太阳、火星、土星、水星与十宫宫主的力量。只给角色倾向和适用条件，不等同于职位高低。
- **说成判断**：团队现在缺的是拍板、专业判断、推进执行还是协调关系；他做得最好和最消耗的角色分别是什么。
- **军师**：涉及岗位设计或晋升时，请组织发展、人力资源或所在行业的管理者核实际能力和授权。

## R05 我为什么总在人际里觉得累
- **年份**：这题不报具体年份（今年、这步大运的大气候可以带一句）；最近突然加重时，再按现实事件看是环境变化还是长期模式被触发。
- **盘讲**：八字看印星过多、日主承压和官杀压力等容易吸收、承担或自我要求过高的结构；相关强弱、喜忌只作线索（身强身弱照接口口径，没核过，这条只当线索、不当主依据）。西占看海王星与金星、月亮、七宫的联系，以及十二宫的边界与退隐主题。印占看十二宫宫主与七宫、月亮的联系及计都的抽离倾向。只讲消耗机制和边界，不把疲惫全归因于性格。
- **说成判断**：累主要来自照顾情绪、承担责任、猜测别人，还是无法拒绝；哪些关系让他恢复，哪些关系持续透支。
- **军师**：若长期耗竭或伴随明显情绪、睡眠问题，请心理咨询或医疗专业人士评估。
