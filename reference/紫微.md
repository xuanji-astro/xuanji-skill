# 紫微排盘（紫微斗数）

用户说「看看我的紫微」「紫微斗数」「我的命宫是什么星」「我的命盘」「我现在走什么大限」「我的四化」这一类，走这里：先出一份紫微排盘报告（盘和数据，不写解读），再在对话里照下面的读法回答他问的。

## 拿数据

1. 生辰跟单人排盘一样（公历日期、时间、出生城市、性别），同一次对话里已经同意过排盘的不用再问；没同意过，照 `SKILL.md`「数据与范围」那段先问。**没有出生时间排不了紫微**：命宫按时辰安，没有时辰整盘不排，照实说，不用别的顶替。
2. 照第 2 步私有创建 `ziwei_request.json`，只放这几样：`date`、`time`、`city`、`gender`，可选 `time_source`、`time_precision`。不要把 `answers`、`calib` 放进来。
3. 拿整盘：

```bash
node <skill目录>/scripts/client.mjs ziwei --input ziwei_request.json --output ziwei.json
```

口径（服务端定，不自己改）：三合派通行安星；时辰用跟八字同一个真太阳时，23 点以后算第二天子时；年按农历正月初一换；闰月前半月算本月、十六起算下月。`time.near_boundary` 是 true（离时辰交界 15 分钟以内），命宫可能差一格，照实说一句；要定下来走 [定时辰](定时辰.md)。

## 出报告

```bash
node <skill目录>/scripts/build_ziwei.mjs --ziwei ziwei.json --out 紫微排盘.html --pdf 紫微排盘.pdf --pack 紫微数据包.txt --zip 紫微排盘.zip
```

- `REPORT_SAVED`、`PDF_SAVED`、`PACK_SAVED`、`ZIP_SAVED` 都出来了，就把压缩包交给他；`PDF_SKIPPED_…` 时压缩包里只有网页版和数据包，照第 6 步说明。
- `ZIWEI_TIME_UNKNOWN`：没有出生时间，照实说排不了紫微。
- `OUTPUT_EXISTS` 换个文件名；`REPORT_INCOMPLETE`、`ZIWEI_INVALID` 什么都不给，照第 6 步请他加创始人微信。
- 交压缩包时说一句：里面是紫微排盘报告（PDF 和网页版）和一份「紫微数据包.txt」，数据包可以整段贴给手机上别的 AI 接着聊；想照玄玑的读法深聊，就在这里接着问。

报告里是十二宫盘面（主星、辅星、亮度、生年四化）、十二宫细表（含杂曜）、生年／大限／三年流年四化、大限表和流年命宫，没有解读文字。盘面中间跟吉真这类排盘软件一样印真太阳时、北京时间、农历时间和节气四柱（不印出生地点）；数据包不印出生日期、钟点和农历，但盘面推算结果仍是他的个人信息。

## 对话里怎么读

先问他最想知道什么；他没说，就挑跟他最有关的两三样讲，一次不倒完。每句话都要能指回 `ziwei.json` 里的字段，没给的星、宫、四化不自己推算。读盘先看 `紫微数据包.txt`（四化、今天农历、今年还没过的流月都写成了字），细节再查 `ziwei.json`；`ziwei.json` 里的四化数组（`mutagen`）是四颗星按 禄、权、科、忌 的顺序排的，第一颗化禄、第四颗化忌，别数错位。口味：夸他盘里真有的事，只照见不打脸，落陷只说「力气换地方使」，不否定星，不说别人病。

**宫名、星名照说，先报盘面再落到人**：看紫微的人就是要听这些词。宫名、星名、四化、庙旺、大限流年都直接说，不算 SKILL.md「术语一段最多一个」的数。讲一处照这个顺序：先报盘面（哪一宫、坐什么星、亮度、化什么），再说这颗星管什么、这个亮度说明什么，最后落到他身上是什么样——他听得出每句话是从盘上哪一格来的。一宫一段讲透：星管什么、亮度、四化、三方四正里冲它帮它的星、落到他身上是什么样，都讲到；段尾不另加一句总结，整次回话最多留一句收束的话。

**盘上有的说满，盘外的情节不编**：星什么样、这一宫什么调子、这十年这一年什么气候，照 SKILL.md「话说肯定」直接说。他生活里具体发生了什么（事情已经在办、拖了多久、以前经历过几回、谁在给他送钱），盘上看不到，不当事实讲；要用，就说成一句判断、末尾请他对一下，他认了顺着往下讲，不认换一层说，不绕回来圆。一次回话最多这样问一处。

1. **先看命宫这一格**：命宫主星＋亮度（`palaces[].major[].brightness`）。双星同宫两颗都说，主调看哪颗更亮、哪颗带四化。命宫无主星（空宫）借对宫迁移的主星说，明说"是借的，劲道打一折"。身宫＝后半生使劲的方向，三十岁以后越来越像身宫那一宫——身宫落哪宫，就说哪宫的主题。讲性格落到他生活里会遇到的事上。
2. **三方四正一起看**：命宫、财帛、官禄、迁移是一个架子的四条腿。讲命宫的星，必须带过对宫和三合的星（煞星从对宫冲照要提一句）。他问哪一宫，那一宫也照这个法子看它自己的三方四正。
3. **生年四化定亲疏**：禄＝顺、得、有人送上门；权＝抓得住、说了算；科＝被看见、名声贵人；忌＝最在意、最磕绊——忌不当灾说，说"你在这一块格外上心，磕绊最多，熬过去恰恰是最硬的底牌"。四化落哪宫，那块人生就带这个调。化忌冲对宫（忌冲）比坐宫更费劲，照实讲，不吓人。
4. **现在走到哪**：先看当前大限（`now.decadal`：哪一宫、干支、大限四化）——这十年是什么气候；大限命宫的主星当这十年的"我"讲。再看流年（`now.years`：流年命宫、流年四化）——今年落在哪宫、引动什么。今天是农历几月看 `now.lunar_today`；流月看 `now.years[0].months`，`when` 是 `past` 的已经过了，不当窗口讲，`now` 是这个月。只讲气候和路数，不断某一天一定发生什么。大限或流年的四化跟生年四化叠上同一颗星（比如生年忌被流年忌引动），那一年那块事会特别有感，可以讲重一点。大限每宫起止岁数照抄字段，不自己推。
5. **亮度、煞星和杂曜**：亮度只说力气大小、力气用在哪，落陷不吓人。擎羊、陀罗、火星、铃星、地空、地劫只当提醒：火星＝急、铃星＝闷、擎羊＝冲、陀罗＝磨、空劫＝想得开也容易落空；不说灾，不卖化解（符、法事、改名、物件一律不推）。杂曜（红鸾、天喜、天姚、天刑这些）只当配角提味道：红鸾天喜＝人缘喜事，天姚＝魅力，天刑＝自律较真——一句带过，不拿杂曜下断语。
6. **跟八字、星盘一起看**：同一件事几套盘都指向，可以说得满一点；只有紫微看到的，说明是紫微这么看。要几套分开说，走分术报告。

古书里的说法翻成他今天的样子讲：「红鸾星动」不说婚期，说人缘旺、心动的年份；「官禄」对有单位的人才是升职，对做事的人是身份立起来、有了自己的作品。不断生死病，不判阶层，钱只讲节奏和守什么、不给买卖点位。

### 三个专题

他问「我是什么样的人」「我会爱上谁」「我的钱从哪来」这类，照下面对应那一题的骨架在对话里讲透（每题一次讲完，不倒别的宫）。

**① 你是谁 · 命宫主星深度报告**
- 看哪几样：命宫主星＋亮度、命宫三方四正（财帛、官禄、迁移）、身宫、生年四化落宫。
- 怎么判：主星定底色，亮度定劲道，三方四正定架子，身宫定后半生方向，四化定亲疏。
- 骨架：底色 → 行事 → 感情 → 得用（这颗星的劲往哪使最顺）→ 注意（满格的代价或力气的换法，各一条，不恐吓）。

**② 你会爱上谁 · 夫妻宫专题**
- 看哪几样：夫妻宫主星＋亮度、夫妻宫三方四正（对宫官禄、福德、迁移）、生年四化里跟感情有关的落宫（禄／忌落夫妻、福德、交友）。男命兼看太阴、女命兼看太阳作参照，一句带过。
- 怎么判：主星定他爱的模样（会爱上哪种人、相处模式），煞星和化忌定磕绊处，大限流年的夫妻宫定这几年感情气候。
- 骨架：你会爱上谁 → 你在关系里的样子 → 磕绊在哪（裹着抱讲）→ 这几年的感情气候。

**③ 你的钱从哪来 · 财帛宫专题**
- 看哪几样：财帛宫主星＋亮度、财帛宫三方四正（对宫福德、合宫命宫、官禄——赚钱跟命和事业分不开，必带）、武曲／天府／太阴三颗财星落哪（格外提一句）、生年四化里跟财有关的落宫（禄／权／忌）。
- 怎么判：主星定进财的姿势（靠本事、靠人脉、靠名声、靠守），四化定财缘深浅，大限流年的财帛宫定这几年的钱景。
- 骨架：你的钱从哪来 → 进财的姿势 → 财上的磕绊（裹着抱讲）→ 这几年的钱景。

专题报告照同一套写法红线：只照见不打脸；落陷不恐吓；不说别人病；每句指回字段，没有的数据不编。

### 做成专题报告

他想要一份能留着看的（说「出个报告」「做成一份」，或者你在对话里讲完一题、问他要不要做成报告他说要），就出这一题的专题报告。一次出一题。篇幅照年度报告写足：报告是他会反复翻、会转给别人看的东西，对话里一两句带过的地方，报告里要讲透。

写 `ziwei_report.json`（私有创建，照 `SKILL.md` 第 2 步）：

- `schema`：`xuanji.ziwei_report/0.1`；`topic`：`ming`（命宫主星）、`fuqi`（夫妻宫）、`caibo`（财帛宫）。
- `cover`：`seen` 三句（一串字、一句一行）——第一句给气势（一句成语或名句），第二句半文半白像口诀（14 到 28 个字）说这一宫的本事，第三句落到他今天的样子；三句里不放宫名、星名、四化、庙陷这些术语，术语挪到 `evidence`（一行小字，写凭哪几颗星）；`stamp` 两个字，这一题的关键词。
- `oneline`：一句话说这一题（60 字以内）。
- `glance.points`：三个要点，每个 `title`（8 字以内）＋`sub`（18 字以内）。
- `sections`：照骨架的段，标题一字不改、顺序不变——命宫主星：底色、行事、感情、得用、注意；夫妻宫：你会爱上谁、你在关系里的样子、磕绊在哪；财帛宫：你的钱从哪来、进财的姿势、财上的磕绊。每段 `paras` 写 3 到 5 段话，每段话 120 到 400 字（骨架的一段合起来至少 500 字），`basis` 写 1 到 4 条盘上依据 `{palace, stars}`：这一段凭哪一宫的哪几颗星（`stars` 是星名的数组），星必须真坐在那一宫。
- `years`：四段话（每段至少 150 字），依次写这步大限、`now.years` 的三年流年（顺序跟数据一样）；这一题在这一段是什么气候、引动了什么、适合做什么。页面会照盘自动画出每一段的四化落哪宫，你不用抄。
- `advisors`：1 到 2 位军师，按这一题挑这一行公认最懂的真人，`{name, title, advice}`，只用公开身份和公开讲过的办法。
- `loop`：`remember` 一句话记住（40 字以内）；`back_msg` 到时候回来发的一句（24 字以内），写成这一题里最可能应验的那件事。
- `next_questions`：三句他会接着问的，用他的口吻。

写法跟对话一样（宫名星名照说、先报盘面再落到人、盘外的情节不编），另外几条程序会查：四化只能写生年、这步大限、这三年流年给过的那几个，写「某星化某」要对得上；写「某星（亮度）」的亮度照盘抄；写「某星化某在某宫」，那颗星得真坐在那一宫（四化跟着星走，星在哪宫，化就在哪宫）；不写「那股劲」「这股劲」「带劲」「概率」「判词」、百分比和方头括号；「亮」字别连着拿来做比喻，整份最多三次（「亮度」「月亮」不算）。

```bash
node <skill目录>/scripts/build_doc.mjs --kind ziwei --ziwei ziwei.json --report ziwei_report.json --out 紫微_夫妻宫.html --pdf 紫微_夫妻宫.pdf
```

文件名跟题目走（`紫微_命宫主星`、`紫微_夫妻宫`、`紫微_财帛宫`）。`REPORT_RULES_FAILED` 照 `REPORT_RULES_HINT` 给的类别和字段改了再跑（`ZIWEI_SIHUA`、`ZIWEI_BRIGHTNESS` 是正文里的四化或亮度跟盘对不上，`ZIWEI_PALACE` 是写的四化落宫跟星所在的宫对不上，`ZIWEI_BASIS` 是依据里的星不在那一宫，`ZIWEI_SECTIONS` 是段的标题或顺序不对，`LENGTH_SHORT` 是写短了，`REPEATED_LIANG` 是「亮」字用多了）；`REPORT_INCOMPLETE` 什么都不给，照 `SKILL.md` 第 6 步请他加创始人微信。交报告时说一句：这是紫微××专题，网页版和 PDF 各一份。
